## 3. 기획 개요 (분석·활용 개요)

▸ 칸이 작을 때 쓰는 **짧은 버전 (약 200자)**

```
산림청 국가승인통계 4종의 마이크로데이터를 계층적으로 결합해, 개별 임가의 조건에
맞는 수익성을 예측하고 무엇을 바꾸면 나아지는지 제시하는 시스템입니다. 현행 공표
방식인 지역·업종 단순 평균 대비 예측 설명력을 4.05배 높였으며, 출하시기·판매처·
품질등급·보조사업까지 이어지는 실행 가능한 개선안을 임가가 읽을 수 있는 말로
전달하는 웹 서비스로 구현했습니다.
```

▸ 칸이 넉넉할 때 쓰는 **표준 버전 (약 550자)**

```
현행 임업통계는 전국·지역·업종 단위의 거시 평균으로 공표되어, 개별 임가가
"내 조건에서 얼마를 벌 수 있는가"에 답하지 못합니다. 실제로 지역별×업종별 단순
평균을 예측기로 세워 검증한 결과 설명력이 R² 0.043에 그쳤습니다. 평균값은 개별
임가 성과의 4.3%밖에 설명하지 못한다는 뜻입니다.

본 과제는 임가경제조사·임산물생산비조사·임산물생산조사·임업경영실태조사 4종의
마이크로데이터를 계층으로 결합했습니다. 임가 단위 종합 수익성은 Model A가,
품목 단위 정밀 진단은 Model B가 담당하며, 두 모델 모두 CUDA XGBoost와 Optuna
교차검증으로 최적화했습니다. 그 결과 Model A는 현행 방식 대비 4.05배(R² 0.174),
Model B는 5.95배(R² 0.624)의 설명력을 확보했습니다.

여기에 KAMIS 도매가격·산림청 보조금 세부사업·기상청 지상관측을 융복합해,
언제·어디에 팔지, 등급을 어떻게 관리할지, 어떤 보조사업을 쓸지까지 금액으로
환산해 제시합니다. 결과물은 임가가 네 가지만 고르면 답이 나오는 웹 서비스
(FastAPI + Vue 3)와 전 과정을 재현할 수 있는 분석 코드입니다.
```

## 모델 성능 (Test set)

| 모델 | 현행 단순평균 | 다중 선형회귀 | **제안 모델** | 개선 |
|---|---:|---:|---:|---|
| **Model A** (임가경제조사) | R² 0.0428 | 0.1295 | **0.1736** | **4.05배** · MAE 10.2% 감소 |
| **Model B** (임산물생산비조사) | R² 0.1049 | 0.4894 | **0.6243** | **5.95배** · MAE 37.7% 감소 |

- 교차검증 OOF와 Test 성능이 유사해 **과적합 없음** (A: 0.199 vs 0.174, B: 0.639 vs 0.624)
- 예측구간 포함률 A **78.2%**, B **76.5%** (명목 80%) — 캘리브레이션 양호

## 방법론에서 강조할 점

**① 정보 누출 통제 — 성능을 부풀리지 않았습니다**
Model B 1차 학습에서 R² 0.9102가 나와 검증한 결과, 총생산액·부가가치·등급별 수량이
설명변수에 섞여 있었습니다. 수량 × 단가 = 총수입이므로 목표변수가 그대로 복원되는
구조였습니다. 규칙을 강화해 0.6243으로 내려왔고, 목표변수와의 최고 상관도
0.885 → 0.344로 정상화되었습니다. **이 경위를 보고서에 그대로 기재했습니다.**

**② 연도별 스키마 불일치 해소**
2021년 임가경제조사만 영문 변수코드 접두사가 붙고, `임외소득`↔`임업외소득`처럼
항목명이 바뀌며, 생산비조사 「경영수준별」은 2022년까지 5·6, 2023년부터 1·2를 씁니다.
마지막 항목은 **파일설계서에 문서화조차 되어 있지 않아**, 조화하지 않으면 동일 개념이
연도 코호트로 오분할됩니다(2,239행 영향).

**③ 가설을 실제로 검증**
"R²가 낮은 것은 기상 등 미관측 요인 때문"이라는 설명을 검증하기 위해 기상 자료를
실제로 결합했습니다. 성능이 오히려 하락했고, 원인은 임가경제조사의 지역 구분이
**시도 9개뿐**이라는 데 있었습니다. 이는 통계 개선 제언(공간 해상도 확대)의
실증 근거가 되었습니다.

## 통계 개선 제언 (6건)

1. 연도별 스키마·코드 체계 표준화 및 변경 이력 명시
2. 전 연도 파일설계서 제공
3. 단위 표기 명시 (경영실태조사 판매수입·판매량에 단위 없음)
4. **조사 간 임가 단위 연계키 제공** ★
5. **시군구 코드·임지 좌표 등 공간 해상도 확대** ★
6. 표고 등 소표본 품목 조사 확대
